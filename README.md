## Overview

This repository contains my personal portfolio website built to present data projects with a more polished and modern frontend experience.  
The goal is to make technical work feel clear, professional, and easy to trust at first glance.

## What This Portfolio Uses

| Area | Tools |
| --- | --- |
| Framework | React 19 |
| Build Tool | Vite 8 |
| Styling | Tailwind CSS 4 |
| Motion | Framer Motion |
| Icons | Lucide React |
| Language | JavaScript (JSX) |

## Highlights

- Animated hero, cards, and section reveals using `framer-motion`
- Responsive single-page layout for laptop and mobile screens
- Glassmorphism-inspired UI with layered gradients and glow effects
- Full Light & Dark Mode toggle running natively on CSS variables
- Smooth section scrolling with sticky navigation
- Portfolio sections for About, Skills, Projects, and Contact
- Clean component structure centered in `src/App.jsx`

## Local Setup

```powershell
npm install
npm run dev
```

Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

## Production Build

```powershell
npm run build
```

## Customization Before Publishing

Update the `profile` object in `src/App.jsx`:

- `email`
- `github`
- `linkedin`
- `resume`

Update each project link too:

- `caseStudy`
- `github`
