## ✨ Key Features & Capabilities

* 🌗 **True Dual-Mode Architecture:** Seamless toggle between a stark white editorial layout and a deep glass-morphism dark mode—powered natively by dynamic CSS variables.
* 🚀 **Silky Scrolling & Interactions:** Employs `framer-motion` for complex scroll-triggered enter animations, hover scaling, and polished element offsets.
* 💎 **Premium Aesthetic Layout:** Avoids standard blocky templates by layering UI elements via backdrop-blurs (`backdrop-blur-xl`), complex translucent borders, and gradient drop shadows.
* 📱 **Flawless Responsiveness:** Optimized grid structures adapt layout density precisely from high-res ultrawide desktop monitors down to mobile viewports.
* 🎯 **Recruiter-Centric Design:** Places extreme emphasis on the "Contact" flow, ensuring resumes, Github, and LinkedIn actions are heavily anchored.

## 🚀 Getting Started

### 1. Clone the environment
Install the dependencies using your package manager of choice:
```bash
npm install
```

### 2. Boot the Local Server
Run the Vite development server to view the UI live with Hot-Module-Replacement:
```bash
npm run dev
```
Navigate to [`http://localhost:5173`](http://localhost:5173) in your browser.

### 3. Generate Production Build
When the content is locked in and ready for hosting (Vercel, Netlify, Github Pages):
```bash
npm run build
```

## ⚙️ Content Customization

Everything regarding personal identity and metadata is centralized in **`src/App.jsx`**.

To personalize the portfolio before deploying:
1. Locate the `profile` constant object at the top of the file.
2. Replace the placeholder details with your own configuration:
   - `name` & `role` (Updates Hero and Navbar)
   - `email`, `github`, `linkedin` (Updates contact cards)
   - `resume` (Links to a live hosted PDF or local `/resume.pdf` in your public folder)
3. Locate the `projects` array and update the localized metrics, code branches, and summaries.
